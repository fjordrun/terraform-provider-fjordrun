# Fjordrun Provider

Manage [Fjordrun](https://fjordrun.com) infrastructure with Terraform or OpenTofu: teams, projects, environments,
services, functions, domains, volumes, private networks, agents and workflows.

## Example

```terraform
terraform {
  required_version = ">= 1.5"

  required_providers {
    fjordrun = {
      source = "fjordrun/fjordrun"
    }
  }
}

# Takes the token from FJORDRUN_TOKEN.
provider "fjordrun" {}
```

## Authentication

Set `FJORDRUN_TOKEN`, or the provider's `token`, to one of:

- A **team API token** (`fjr_...`), from Team settings → API tokens. Right for pipelines that manage one team or one
  project. It acts with the role of the person who created it.
- A **personal access token** (`fjr_pat_...`), from `fjordrun login`. It acts as you, in all your teams.

Team tokens can't create teams, create other tokens, or manage SSH keys: those need a personal access token. When the API
refuses something for a role, a token's scope or a plan's limits, the error shows its reason.

The data sources `fjordrun_meta`, `fjordrun_models`, `fjordrun_pricing` and `fjordrun_templates` work without a token.

## What to know before you start

- **Nothing deploys by itself, unless you ask.** Resources save changes without restarting anything. A
  `fjordrun_deployment` rolls them out, once per apply, after everything else is in place. See
  [Deployments](guides/deployments).
- **Services exist in every environment** of their project, with settings per environment. See
  [Environments](guides/environments).
- **Some secrets live in the state**, because the API can't return them: team secrets, team tokens, and more. Use an
  encrypted remote backend. See [Secrets and state](guides/secrets-and-state).
- **Destroying data is permanent.** Volumes, and the services, environments and projects that hold them, take their data
  with them. Use `lifecycle { prevent_destroy = true }` on anything you can't lose.
- **SFTP and SSH servers are temporary.** See [On-demand servers](guides/on-demand-servers).

## Schema

### Optional

- `api_url` (String) API origin, without `/api/v1`. Defaults to the `FJORDRUN_API_URL` environment variable, else `https://api.fjordrun.com`.
- `auto_deploy` (Boolean) Default for the `auto_deploy` attribute of resources that change what a service runs. Defaults to the `FJORDRUN_AUTO_DEPLOY` environment variable, else `true`: resources deploy when created or changed. Set `false` to save changes without a deployment and roll them out together, once per apply, through `fjordrun_deployment`.
- `token` (String, Sensitive) API token: a team API token (`fjr_...`) or a personal access token (`fjr_pat_...`). Defaults to the `FJORDRUN_TOKEN` environment variable. Some operations are refused for team tokens (creating teams and tokens, SSH keys); use a personal access token for those.
